# Temple Escape v2.0 — The Descent

**The game has been rebuilt into a slower, more atmospheric survival-horror experience.**

## Highlights

- Removed the five-minute timer entirely.
- Added a visible first-person flashlight and arms/viewmodel.
- Rebuilt the entity as a code-rigged articulated character.
- Added dedicated walking/chasing and vent-crawling poses.
- Replaced simplistic roaming with A* navigation and patrol / investigate / hunt / search states.
- Enemy reacts to line of sight, sprint noise, last-known position, and flashlight exposure.
- Added a connected vent system that both the player and entity can crawl through.
- Added close-range camera-space jumpscare/capture sequence.
- Added procedural 9×9 temple generation with extra loops for less predictable chases.
- Reworked the objective: restore three seal mechanisms, then reach the descent gate.
- Added procedural stone, floor and rusted-metal materials; columns, rubble, fog, dust, torch flicker and shadows.
- Added procedural Web Audio ambience, footsteps, vent sounds, whispers and jumpscare stingers.
- Added Low / Medium / High / Ultra graphics presets, render scale, FOV, sensitivity, head-bob and film-grain controls.
- Settings persist between runs.

## Controls

`WASD` move · `Mouse` look · `Shift` sprint · `Ctrl/C` crouch/crawl · `F` flashlight · `E` interact · `Space` jump · `Esc` pause
